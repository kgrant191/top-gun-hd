# Before/after media

The four README images and the separate 65-second vertical video are actual
emulator output, composed with `scripts/build_promo.py`. Original NES graphics
appear above the HD pack at the same replay input. Native frames use nearest
neighbor scaling; HD frames use Lanczos scaling. Both retain the full 256:240
frame ratio. The canvas is 1080×1920, with no gameplay cropped.

The video is delivered separately and is not included in Git or generated by
the release workflow. The workflow packages the installable pack, the four
images and their checksums.

The source cadence is 60.098811 frames per second. Both views receive the same
trim and conversion to 60 fps. One native game-audio track accompanies each
pair; 35 ms audio fades soften the cuts. The source AVI's first frame maps to
replay input 2, while the separate WAV starts at input 1. The composition
script accounts for that one-frame offset.

Every capture pair has identical RAM/nametable/OAM/palette traces, CHR traces
and PCM audio. Existing approved captures are reused for scenes whose artwork
is unchanged by later builds; the victory sequence uses v0.15.1. The release
preserves all approved v0.15.1 PNGs and mapping rules. See
`validation/promotion_v1.0.0.json` and `validation/release_v1.0.0.json`.

## Reproduction

Rendering needs FFmpeg, Pillow and the private emulator recordings. These
large captures and the ROM are not distributed. Create a JSON manifest using
this structure (paths point to your own matching captures):

```json
{
  "captures": {
    "launch": {
      "native": "/path/to/original_replay.avi",
      "hd": "/path/to/hd_replay.avi",
      "audio": "/path/to/original_replay.wav"
    }
  },
  "stills": [
    {"capture": "launch", "input": 2160, "title": "Carrier launch", "slug": "Carrier_Launch"}
  ],
  "segments": [
    {"capture": "launch", "input": 2005, "seconds": 3, "title": "Carrier launch"}
  ]
}
```

```sh
python scripts/build_promo.py /path/to/capture_manifest.json --out output/promotion
```

The still numbering follows manifest order. Add `--stills-only` to skip video
encoding. The release's four still selections and full video sequence are
listed above.
