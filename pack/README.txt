INSTALL
Copy all files from this ZIP into your existing Top Gun HD pack folder,
replacing files when prompted. Enable HD packs and reopen the ROM.
Only the contents of pack/ belong in the emulator's HD pack directory.
No ROM or emulator is included.

SCOPE
The supplied recording covers Mission 3 through refueling, further combat
and game over. The enemy base/boss, Mission 3 landing, later missions and
unrecorded outcomes still need additional work and testing.
This is an unfinished development build, not a full-game release.
